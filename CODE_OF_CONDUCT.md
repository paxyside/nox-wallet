# Code of Conduct

Short version: be civil, focus on the work, don't be cruel.

## What's expected

- **Treat people as adults.** Disagree with ideas, not with people.
  Hard technical criticism is welcome; personal attacks are not.
- **Stay on topic.** Issues and PRs are about the code. Politics,
  religion, market speculation, and tribal flame wars belong
  elsewhere.
- **Respect time.** Don't ping for "any update?" on a weekend. Don't
  bump every 24 hours. People here have lives.
- **Speak in good faith.** Assume the other party has a reasonable
  reason for their position until proven otherwise.

## What's not OK

- Personal insults, slurs, doxxing, harassment in any form.
- Sexually explicit content, imagery, or commentary.
- Threats of violence, including jokes that read as threats.
- Persistent pile-on against any single contributor.
- Using the project, the issue tracker, or the PR queue to promote
  unrelated commercial activity (token shills, "join my discord",
  affiliate links).

## Enforcement

This is a small project. If something violates the rules, the
project owner removes the content and bans the account. There's no
committee, no appeals process, and no due-process theater — the
project owner's call is final.

If you can't reach the project owner through GitHub for any reason,
the email in [`SECURITY.md`](SECURITY.md) works.

## Scope

These rules apply to every interaction tied to this repository:
issues, PRs, commit messages, comments, and any chat channel where
the project is being discussed.
